# API Reference Guide[#](#api-reference-guide)
Coffea: a column object framework for effective analysis.
When executing
```
import coffea
```
a subset of the full coffea package is imported into the python environment.
Some packages must be imported explicitly, so as to avoid importing unnecessary
and/or heavy dependencies. Below lists the packages available in the `coffea` namespace.
Under that, we list documentation for some of the coffea packages that need to be
imported explicitly.

coffea.dataset\_tools.rucio\_utils.get\_dataset\_files\_replicas(*dataset*, *allowlist\_sites=None*, *blocklist\_sites=None*, *regex\_sites=None*, *mode='full'*, *partial\_allowed=False*, *client=None*, *scope='cms'*)[[source]](http://github.com/scikit-hep/coffea/blob/bfc8fd2cf7619a2c7b48fea0326b10af7ed9dba6/src/coffea/dataset_tools/rucio_utils.py#L131)[#](#coffea.dataset_tools.rucio_utils.get_dataset_files_replicas)
This function queries the Rucio server to get information about the location
of all the replicas of the files in a CMS dataset.
The sites can be filtered in 3 different ways:
- `allowlist_sites`: list of sites to select from. If the file is not found there, raise an Exception.
- `blocklist_sites`: list of sites to avoid. If the file has no left site, raise an Exception
- `regex_sites`: regex expression to restrict the list of sites.
The fileset returned by the function is controlled by the `mode` parameter:
- “full”: returns the full set of replicas and sites (passing the filtering parameters)
- “first”: returns the first replica found for each file
- “best”: to be implemented (ServiceX..)
- “roundrobin”: try to distribute the replicas over different sites
Parameters:
* **dataset** ([`str`](https://docs.python.org/3/library/stdtypes.html#str)) – The dataset to search for.
* **allowlist\_sites** ([`list`](https://docs.python.org/3/library/stdtypes.html#list) or [`None`](https://docs.python.org/3/library/constants.html#None)) – List of sites to select from. If the file is not found there, raise an Exception.
* **blocklist\_sites** ([`list`](https://docs.python.org/3/library/stdtypes.html#list) or [`None`](https://docs.python.org/3/library/constants.html#None)) – List of sites to avoid. If the file has no left site, raise an Exception.
* **regex\_sites** ([`list`](https://docs.python.org/3/library/stdtypes.html#list) or [`None`](https://docs.python.org/3/library/constants.html#None)) – Regex expression to restrict the list of sites.
* **mode** ([`str`](https://docs.python.org/3/library/stdtypes.html#str), *default* `"full"`) – One of “full”, “first”, “best”, or “roundrobin”. Behavior of each described above.
* **client** (`rucio.client.Client` or [`None`](https://docs.python.org/3/library/constants.html#None), *optional*) – The rucio client to use. If not provided, one will be generated for you.
* **partial\_allowed** ([`bool`](https://docs.python.org/3/library/functions.html#bool), *default* [`False`](https://docs.python.org/3/library/constants.html#False)) – If False, throws an exception if any file in the dataset cannot be found. If True,
will find as many files from the dataset as it can.
* **scope** ([`str`](https://docs.python.org/3/library/stdtypes.html#str), *default* `"cms"`) – The scope for rucio to search through.
Returns:
* **files** ([`list`](https://docs.python.org/3/library/stdtypes.html#list)) – Depending on `mode`. For `"full"` this is the list of replicas per file;
for `"first"` it contains only the first replica per file.
* **sites** ([`list`](https://docs.python.org/3/library/stdtypes.html#list)) – Depending on `mode`. For `"full"` this is the list of sites where each
file replica is available; for `"first"` it contains the site of the first
replica.
* **sites\_counts** ([`dict`](https://docs.python.org/3/library/stdtypes.html#dict)) – Metadata counting the coverage of the dataset by site.
